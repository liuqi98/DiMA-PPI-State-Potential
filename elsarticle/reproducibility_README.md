# DiMA-PPI peer-review reproducibility bundle

This bundle accompanies the manuscript and contains the analysis/training scripts, processed summary tables, canonical-state audit, held-out path/cycle audit, strict-partition bootstrap results, and out-of-fold predictions used for the reported state-potential comparisons.

The canonical manuscript sources are `kbs_antisymmetry_manuscript.tex` and `kbs_supplementary_material.tex`. The primary model is the canonical four-state shared-potential formulation and uses no antisymmetry coefficient. Historical fixed-weight and nested soft-consistency runs are retained only as secondary mechanism diagnostics. The bundle includes the six-model S1129 comparison, four-state versus no-state complex bootstrap, complete real-state integrability audit, and final sequence/interface strict-split analyses.

Large pretrained language-model weights, source PDB files, and third-party benchmark repositories are not redistributed. Their public sources and versions are identified in the manuscript and run scripts.
